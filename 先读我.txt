康晋电气手势控制平台 1.0.0

Windows 10/11 64 位 x64 运行包

1. 完整解压整个 ZIP 到可写目录，建议 D:\GestureControl。
2. 双击 CHECK.cmd，等待出现 CHECK PASSED。
3. 双击 START.cmd，保持服务窗口开启，浏览器会自动打开大屏。
4. 在宣传片页面点击“开始播放”，再点右上角“管理后台”。
5. 进入设置，连接摄像头，做比耶 V 手势锁定主控。
6. 在工作流页检查适用页面、动作和启用状态，再返回大屏验证。

默认端口为 8000，被占用时自动向后选择，以启动窗口显示的网址为准。
结束演示时，在服务窗口按 Ctrl+C 停止程序。
配置备份：双击 BACKUP.cmd；媒体和 PPT 文件需另外备份。

文档位于 docs 目录，提供 PDF、Word 和 Markdown：
- Windows部署说明：部署、自检、网络、可选 PPT、备份与升级。
- 操作手册：大屏、摄像头、主控锁定、工作流、网页与 AI 操作。
- 交付验收记录：本次测试范围、结果和现场验收项。

运行包内置 Python、依赖、模型和企业宣传片。
未附带 AI API Key、摄像头凭证、PowerPoint 软件或 PPT 文稿。
普通编辑和模拟可离线使用；摄像头、AI 与外部网站需满足对应的连接条件。

若手中是 Source 源码包，请按部署说明运行 setup.ps1 和 run.ps1。
